# Dataset-specific estimator configurations

Only configurations whose topic, message layout, timing encoding, and
extrinsics have been inspected belong here. A catalog entry alone is not enough
evidence to create an estimator configuration.

`aist-mid360-drive.yaml` preserves the currently validated PointCloud2 contract.
M3DGR and TIERS configurations remain intentionally absent until their bags are
obtained and inspected; catalog metadata must not be treated as a sensor
calibration.

# Named external/runtime contracts still open

1. **PX4 Hold completion and takeover.** Pinned adapter source and six raw Hold episodes distinguish request, command ACK and AUTO_LOITER status. The additional O1-R09 LOITER callback is `Rejected`, not Success. These observations do not establish that a future `ModeCompleted(Success)` for persistent LOITER means entry, eventual exit, or completion, nor the exact firmware behavior for deactivation/operator/failsafe. The shadow keeps each fact and labels only fresh status as “Hold observed”. A product retry/authority-transfer policy must be validated against the exact PX4 firmware revision and focused mode tests before migration of the adapter boundary.
2. **E2 exported `MissionController::onTrajectory`.** Source permits a successful non-stop callback to leave Braking before measured stop; the audited product call graph did not establish an internal producer. The shadow names this `ExternalRecoveryApi/UnknownOwner`. Do not delete or silently reinterpret that exported API in the first cut; use a separate caller/ABI review when that boundary migrates.
3. **Real timing envelope.** Command publish→receive quantiles from C use common simulated `/clock`; zero-tick observations are not transport latency. Recertification, queue, scheduler and PX4 response tails are not measured as a representative distribution. The architecture can be designed without changing 100 ms lease or 500 ms world gate, but authority cutover/qualification requires timing evidence.
4. **Physical route projection from trace.** Replay has source-certified crossing flags, sample stamps and waypoint ordinal, but not complete 3-D route geometry or every measured P/V/A sample. Self-intersection/reverse correctness is source/model evidence only. Product migration needs focused geometry/component tests with real route snapshots.

These are named blockers to **authority migration/qualification**, not a reason to abandon the diagnostic architecture decision. No new product instrumentation is requested by this branch.

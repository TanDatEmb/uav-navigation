# State Admission Test

Scope: every mutable reducer state slot in `model.py`, including `HoldTransfer` and diagnostic quality. Sole writer for all rows is the `ShadowReducer` replay/event transition; CLI/report code has no product writer. Value objects are immutable event payloads copied into those slots. The “need” column answers independent information, exact derivability, and loss on removal; “life” answers why it survives, creation and invalidation; “form” answers exclusivity, enum/variant, and authority/observation/temporal/diagnostic classification. Each row names a test/invariant. No row is merely a convenience cache.

| Persistent slot | Need; not exactly derivable from remaining slots | Life: start → invalidation | Form / invariant / test |
|---|---|---|---|
| Mission.route | Mission, route revision and localization are the crossing identity; cannot infer from cursor alone. | New route event → revision/reset. | Mission authority identity; PT4/PT5. |
| Mission.measured | Latest ordered physical cursor survives callbacks; accepted gate cannot imply physical location. | Measured sample → reset/new measured sample. | Temporal measurement; PT2/PT3/self-intersection. |
| Mission.crossing | Before/after source samples and measured gate witness are not reconstructable from a later cursor alone, especially after leaving ball. | Valid measured segment/ball → consume, route/gate/reset/reverse. | Typed temporal witness, not bool; PT2–PT6. In production it may be derived only if complete cursor history is retained. |
| Mission.accepted_waypoint | Policy acceptance is distinct from measured motion. | Acceptance → mission reset/new acceptance. | Mission authority; PT1/PT2/STOP. |
| Mission.gate | Current waypoint plus request ID needed to reject old crossing/continuation. | Gate input → next gate/reset. | Mission authority identity; wrong-request test. |
| Mission.continuation_witness | Successor readiness is independent of measured crossing. | Certified continuation event → gate/reset/consumption. | Immutable observation, source-validated identity; PT1/PT2/wrong-request. |

**Immutable payload fields admitted:** `RouteIdentity(mission, revision, localization)` distinguishes overlapping missions and resets; `RouteCursor(segment, u, source_stamp_ns, sample_sequence)` preserves branch, progress, source time and sample ordering; `Crossing(route, waypoint, before, after, error_m, quality, kind, request_id)` preserves the measured physical fact and its proof; `ContinuationWitness(route, waypoint, request_id, bundle_generation)` authenticates successor readiness; `ContextKey(localization, mission, route, world_generation, world_revision, goal_epoch, waypoint, request_id, dynamics_hash)` supports one stale-result comparison; `Trajectory(generation, role, context, certificate_expiry_ns)` preserves active certified authority; `ProtocolWitness(stamp_ns, value, quality)` preserves source time/value/evidence grade. `LocalBoundaryWitness(localization_epoch, state_source_stamp_ns, state_receive_stamp_ns, px4_source_stamp_ns, px4_receive_stamp_ns, frame_generation, position_ned, velocity_ned, translation_ned, heading_ned, health_state, health_source_stamp_ns)` preserves local physical/frame/health evidence as one immutable boundary receipt; each member carries distinct source, frame or physical information and is invalidated as a unit on reset/newer sample. The existing audit stream lacks a complete receipt, so replay never fabricates one. Each immutable member is created with its enclosing event witness and invalidated with that witness. None is independently writable or a second authority representation. Optional `u` remains `Unknown` when current trace has no geometry; production must populate them to handle self-intersection.

**Admission limits:** `Mission.measured` and `Mission.crossing` overlap by design but carry non-equivalent temporal information. A production implementation may replace them with a sufficient ordered cursor history only after PT2/PT3 proof. `Execution.phase` plus optional payloads can express illegal combinations in Python; transition methods/test enforce them here, while production should use tagged payloads. `Shadow.evidence` is currently run-level; report comparisons only use it when the causal episode has a known gap. It is never product authority.

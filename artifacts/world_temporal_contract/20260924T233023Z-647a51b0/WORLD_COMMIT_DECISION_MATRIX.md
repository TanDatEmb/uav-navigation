# WorldCommitDecision disposition matrix (AS-IS)

| Decision | Source cause | World pointer | Active | Pending | Mapping worker / runtime |
|---|---|---|---|---|---|
| `kCommitted` | exact timeline and prior-world still current; identity advances; active retained+recertified or exact active revoked; pending independently retained/dropped | New snapshot becomes visible after execution finalizer | Retained on validated exact active; otherwise removed and lifecycle failed | Independently validated successor retained or dropped; if no active, dropped | Epoch readiness may reopen; exact revocation side effects run. |
| `kNoPublishedWorld` | Decision exists in world authorizer path when candidate/finalization asks for latest but none exists | no publication | commit callback not invoked | unchanged | Must be classified by caller; the current mapping transaction normally has a current/initial immutable map. |
| `kWorldAdvanced` | Candidate validation identity no longer equals latest at final authorization | no dependent commit | unchanged | unchanged | Ordinary stale candidate concurrency; caller retries/discards. Mapping publication path does not use this exact return as normal stale publication. |
| `kSuperseded` | execution timeline/pointers/prior world changed after expensive validation | no new world publication | newer/current execution preserved | newer/current pending preserved | Explicit normal optimistic concurrency; runtime records and returns. |
| `kCancelled` | finalize returned false or threw | no new world publication | expected no dependent mutation unless callback partially mutated (current bounded finalizer is `noexcept`) | same | Mapping callback's current generic noncommitted branch invalidates command and throws. Reachability/policy is not fully exercised. |
| `kCandidateRejected` | invalid identity or active preparation failed; exact current active can be revoked/fail-closed but transaction not consumed | no new world publication | if preparation failed, exact active and staged removed/failure latched; invalid incoming identity can be rejected before mutation | removed when active preparation failure; otherwise untouched | Mapping callback currently invalidates and throws. This is fail-stop for an unpublishable new world after an execution transition failure. |

Important: when active revalidation returns false, runtime passes `retain_validated_bundle=false`; ExecutionAuthority's current transaction removes the exact active and pending state, fails lifecycle, runs finalizer, and returns `kCommitted` so the new world publishes only after command authority has been withdrawn. A pending-only failure while active validates drops pending but retains active.

`WorldSnapshotStore::publishAndFinalizeDecision` leaves old world visible unless finalizer returns `kCommitted`. Its generic catch maps exceptions to `kCancelled`; current callback is deliberately `noexcept` and bounded. The unconditional `command_store->invalidate()` fallback is broader than the typed outcomes and needs explicit negative-path tests/classification before any change.

## State Admission Test (12 questions)

For each potential persistent record, ask: (1) independent information; (2) exact derivability; (3) why survive an event; (4) sole writer; (5) creation event; (6) invalidation; (7) exclusivity; (8) tagged-union alternative; (9) authority or diagnostic; (10) process replica; (11) loss if removed; (12) invariant/test. A failure marks the record `UNRESOLVED`, not an invitation to add a convenience boolean.

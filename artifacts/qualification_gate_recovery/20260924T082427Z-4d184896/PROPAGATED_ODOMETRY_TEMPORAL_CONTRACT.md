# Propagated odometry temporal contract

**Source proof.** `PropagatedOdometryWorker::maybePublish` rejects an estimate whose time is not strictly greater than `last_published_time_`, and advances the source-time publication deadline after successful callback return (`src/estimation/fast_lio_ros/src/propagated_odometry_worker.cpp:574-627`). `RosPropagatedOdometryPublisher::publish` copies public-frame generation, increments `publication_sequence_`, and publishes one typed message (`.../ros_propagated_odometry_publisher.cpp:71-86`). The sequence is monotonic for that publisher instance; a new process may restart it, and epoch is the localization fence. The worker callback can return early on conversion/covariance/public-frame failure; absence of a sideband producer trace does not prove DDS loss.

**Adapter admission.** `NavigationMode::onOdometry` requires nonzero epoch/sequence, frame and finite state, valid typed estimator health, matching localization epoch, increasing sequence, and strictly increasing source timestamp. Only the accepted branch updates `last_odometry_receive_ns_`, `last_odometry_receive_steady_ns_`, odometry snapshot and accepted sequence. A rejected callback does not renew the 200 ms state receive boundary (`navigation_mode_node.cpp:1425-1512`). The new sideband disposition records rejection without changing admission.

**Clock domains.** Source stamp and expected deadline use ROS/simulator time; producer/adapter timestamps ending `_steady_ns` use `std::chrono::steady_clock`/`navigation_common::steadyClockNowNanoseconds`. Differences are valid only within the same steady clock host. ROS-source period and steady arrival gap must be compared, never subtracted directly. The monitor's own steady arrival time is an independent observer, not producer or adapter time.

**Limits.** The diagnostic trace is best effort, opt-in and lossy; missing rows are missing evidence. `publisher_publish_call_steady_ns` to `callback_enter_steady_ns` includes DDS delivery and executor scheduling. It is not pure DDS latency. No safety threshold or source-time admission rule changed.
